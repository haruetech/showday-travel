SHOWDAY 여행 일정 - 사용방법 · API 연동 · 변경 기록
(수정할 때마다 이 파일도 같이 갱신합니다. 최신: 버전 71 / 2026-10-09)

==================================================
1. 사용방법 (카테고리별)
==================================================
[첫 화면]
- 그림이 있는 한 화면: 맨 위 풍경 그림과 검색칸, 주황색 "3번만 눌러 바로 추천", 아래 그림 타일
  (가고 싶은 곳 있어요 / 날짜만 정했어요 / 호텔·기차 예약했어요 / 아직 정한 게 없어요 / 숙소·캠핑 찾기).
  폰(360×740)에서도 스크롤 없이 모두 보입니다. 저장한 여행·작성 중 일정은 아래에 나옵니다.
- 그림은 종이 공예 느낌의 겹겹 풍경(앱 안에 직접 그린 SVG, 외부 이미지 없음)입니다. 서버 연동 후 TourAPI 사진으로 교체 가능.
  그림 수정은 js/home-art.js 한 파일에서 합니다.

[계절 명소] (첫 화면 "계절 명소" 4칸: 봄 벚꽃·꽃길 / 여름 바다·계곡 / 가을 단풍·억새 / 겨울 설경·온천)
- 지금 계절이 맨 앞에 "지금" 표시와 함께 나오고, "지금 N곳 / 곧 N곳"으로 지금 가기 좋은 곳 수를 보여 줍니다.
- 누르면 명소 목록: 계절 탭(봄·여름·가을·겨울), 테마(봄=벚꽃·유채튤립·진달래철쭉·봄 축제 / 여름=바다·계곡숲·수국연꽃·야경·축제 /
  가을=단풍·은행나무·억새갈대·가을 축제 / 겨울=설경·온천·해돋이·축제불빛·겨울꽃), 지역(권역) 선택.
  카드: 🔥지금 한창 / 곧 시작 · N일 뒤 / N개월 뒤, 평년 기준 시기, 한 줄 설명, "○○ 일정 만들기", "올해 단풍·개화 확인"(검색) 링크.
- 시기는 평년 기준 대략값(샘플)입니다. 올해 시기는 "대한민국 구석구석" 단풍지도(한국관광공사·국립수목원 식물계절관측)나
  기상청 날씨누리(주요 21개 산 단풍 관측)에서 확인하세요. 멀리 있는 명소는 가까운 지역(예: 진해→부산, 내장산→전주)으로 이어집니다.
- API: 단풍·개화 시기를 자동으로 가져오는 API는 아직 확인되지 않았습니다(서버 연동 때 공공데이터포털에서
  "식물계절관측"·"계절관측" 자료 제공 여부를 확인). 행사·축제·관광지는 TourAPI로 가능.

[숙소·캠핑 찾기] (처음 화면 "숙소·캠핑부터 찾고 싶다면")
- 1단계(한 화면, 스크롤 없이): 형태(🏨 숙소 / 🏕️ 캠핑·자연) → 누구와·목적(가족·아이, 부모님, 커플, 친구·모임, 혼자, 낚시, 반려동물, 차박;
  다시 누르면 해제) → 어디서(📍 내 위치 / 서울 기준, 거리 ~100·200·300km) → 지역(수도권·강원·충청·전라·경상·제주)
  → 풍경(바다·산·강호수·도시·전통) → 유형. 아래 버튼 "숙소 N곳 보기"에 결과 수가 바로 보입니다.
- 형태별 유형: 숙소=한옥스테이·펜션·리조트·호텔·게스트하우스·템플스테이·농촌체험 민박 / 캠핑·자연=글램핑·카라반·오토캠핑·차박·자연휴양림.
  "차박"을 고르면 자동으로 캠핑·자연으로 바뀝니다.
- 2단계(결과 화면): 가격(1박), 세부 조건(숙소=취사·반려동물·주차·엘리베이터·아이 동반 / 캠핑=장비 없이·반려동물·주차·아이 동반), 정렬(추천·가까운 순·가격 낮은 순), 이름 검색.
  "조건 바꾸기"로 1단계로 돌아갑니다. 카드의 "○○ 일정 만들기"로 그 지역 일정 만들기를 시작합니다.
- 내 위치는 https 공개 주소에서 허용해야 동작합니다. 막힌 화면에서는 서울 기준으로 자동 전환되고 안내가 나옵니다. 거리는 직선 기준 추정입니다.
- 링크: "가격·예약 검색"(네이버), 캠핑은 고캠핑, 휴양림은 숲나들e.
- 숙소 이름·가격·조건은 모두 샘플(추정)입니다. 실제 숙소는 TourAPI(숙박)·고캠핑 API·산림청 휴양림 데이터 연동 후 교체.
- 앞으로 추가하기 좋은 지역 조건: 계절 명소(단풍·꽃), 날씨 좋은 곳(기상청), 이동시간(기차·버스), 혼잡도.
- 일주일·한 달 살기는 별도 사이트(예: stay.showday.kr)로 나중에 만들기로 함. 지역·지도·Supabase·API는 공유.

[일정 만들기]
- "어디서 출발하세요?" 화면의 "📍 내 위치로 알아보기": 폰 위치로 도착지 근처/서울·수도권/다른 지역을 자동으로 고르고,
  다른 지역이면 거리로 편도 시간·왕복 교통비를 추정해 채웁니다(직접 고칠 수 있음). 위치가 막힌 화면에선 직접 고르세요.
- "이런 곳은 어때요?" 화면: 샘플 데이터가 있는 전체 지역(현재 22곳)을 순위로 보여줍니다.
  맨 위 한 줄 "바로 고르기"(🌊바다 보러 · 🚗가까운 곳 · 🍜맛집 여행 · 🧓덜 걷는 곳 · 🎡아이와 체험 · 🎪축제·공연 · 💰알뜰하게)를 누르면
  조건이 한 번에 맞춰집니다. 그 아래 검색칸에서 지역·장소 이름(예: 불국사 → 경주)으로 바로 찾을 수 있고,
  조건 칸에서 카테고리·이동수단(기차·자가용·버스·항공)·편도 시간(1.5~4시간)·정렬(추천순·가까운 순·비용 적은 순)을
  스크롤 없이 한 화면에서 고릅니다. "조건 초기화"로 한 번에 되돌릴 수 있고, "조건에 맞는 N곳"이 바로 보입니다.
  (비용 적은 순 = 교통비+숙박+식비+입장료를 합친 예상 총비용 기준)
  지역마다 이동수단별 시간·왕복 요금이 함께 나오고, 조건에 안 맞는 지역은 접어 두었다가 눌러서 볼 수 있습니다.
  지역: 서울 수원 인천 춘천 강릉 속초 태안 대전 부여·공주 전주 광주 목포 순천 여수 통영 부산 울산 포항 대구 경주 안동 제주
  (서울은 성수·홍대·익선·서촌·이태원·한강 등 동네·카테고리별 장소를 보강)
  출발지를 아직 안 정했으면 맨 위에 "📍 출발지를 먼저 알려 주세요" 안내가 뜨고(서울·수도권/내 위치/도착지 근처 버튼),
  이동수단·편도 시간·정렬 조건은 출발지를 정할 때까지 잠겨 있습니다(카테고리·바로 고르기·검색은 가능).
  시간·요금·좌표는 대략값이며 실제 데이터(관광공사·코레일·항공 등) 연결 후 정확해집니다.
- "어느 지역에서 묵으실래요?" 화면: 위 검색칸에서 숙소·동네 이름으로 찾고, 가격(1박 ~10만/10~15만/15만~)·특징(역·교통, 먹거리, 아이·가족, 조용·온천, 바다·경치)·정렬(추천순/가격 낮은 순/필수 방문지 가까운 순)을 고릅니다. "조건 초기화"로 되돌립니다. 지금 고른 숙소는 항상 목록에 남습니다.
- 처음 화면에서 지역·날짜·인원·숙소·이동수단을 고르면 일정이 만들어집니다.
- 숙소는 날짜(밤)마다 다르게 정할 수 있습니다. 처음 만들 때도 정합니다.

[화면 구성 (폰 · PC)]
- 폰: 위쪽 탭(한눈에/일정/지도/비용)과 일차 버튼이 화면 위에 고정됩니다. 일정·지도 화면에서는 제목을 작게 줄여 공간을 확보합니다.
- PC: 왼쪽 일정 + 오른쪽 지도가 함께 보이고, 한눈에 화면은 2단입니다. 같은 안내가 두 번 나오지 않습니다.
- 여행 중: 위 제목·비용 요약을 숨기고, 길잡이 말풍선이 위에 고정됩니다.
- "지금 위치에서 가는 시간"은 한 줄 요약(추천 방법·시간·금액)만 보이고, "자세히"를 누르면 도보·버스·택시 비교가 펼쳐집니다.

[출발 전 자동 점검] ("한눈에" 탭 맨 위 카드)
- 앱 안 정보로 확인되는 것: 날짜 지남/남은 일수, 월요일에 박물관·미술관이 있는 일차, 마무리가 늦은 날,
  시간이 모자라 빠진 곳, 예산 초과, 숙소 예약 전, 교통편 예매 확인. ⚠️는 확인할 것, ✅는 이상 없음.
- "연결 후 자동 확인" 항목(날씨, 실제 운영시간·휴무, 열차·항공 지연, 버스 도착, 미세먼지)은 API 연결 후 자동으로 채워집니다.
- 자동 확인이 안 되는 것은 공식 안내로 바로 연결: 점검 카드의 기상청·코레일·한국공항공사·한국관광공사 버튼,
  "출발 전 체크"의 장소마다 "운영시간·휴무 검색"(네이버 검색)·"카카오맵" 버튼. 장소 이름으로 검색 주소를 만들어서 항상 열립니다.
  (API 연결 후에는 확인된 곳은 ✅, 불명확한 곳만 링크로 안내하는 방식으로 바꿀 예정)

[마지막 날 귀가 교통 알림]
- 기차·버스·항공으로 온 경우(자가용·근처 거주 제외), 마지막 날 일정 맨 위에 "🚆 귀가 교통 안내" 카드가 나옵니다:
  출발 시각, 역·터미널(공항) 도착 기준(기차 30분·버스 20분·항공 2시간 전), 마지막 장소 마무리 시각, 예매 확인 링크.
- 여행 중 화면이 열려 있으면 알림: 전날 저녁 7시, 출발 2시간 30분 전·1시간 30분 전·30분 전.
  알림 빈도 "끄기"면 안 울리고 "조용히"면 진동 없이 화면 안내만 합니다.
- 출발 시각은 처음 입력한 "돌아가는 시간"이에요. 앱이 닫혀 있을 때의 알림은 서버 연동(푸시) 후 가능합니다.
- "출발 전 자동 점검" 카드에도 귀가 시각 확인 안내가 들어갑니다.

[말·글로 일정 바꾸기] (화면 아래 입력 버튼)
- 예) "4시에 첨성대 행사 있어" -> 그 시간에 맞춰 나머지 일정 조정
- 예) "석굴암 오전으로 바꿔줘" / "불국사 다음 석굴암 넣어줘" (바로 이어서 배치, 시간 모자라면 다른 곳이 제외됨)
- 예) "지금 시간이랑 위치 적용해줘" -> 지금부터 출발(5분 단위 올림)
- 예) 비 와요 / 피곤해요 / 택시 빼줘 / 식당 바꿔줘 / 카페 넣어줘
- 보고 있는 일차에 적용됩니다. 지난 날짜는 바뀌지 않습니다.
- 클로드 앱 안에서는 마이크 버튼이 막힙니다 -> 키보드의 마이크로 말하세요.

[출발 위치 · 출발 시간]
- "출발 위치 바꾸기": 지도앱 링크/좌표 붙여넣기, 앱 안 장소 이름 맞추기,
  "카카오맵에서 찾기", 출발 시간 직접 입력(이 시간에 출발 / 지금 시간으로 / 기본 시간으로).
- 주소 글자만으로는 좌표를 못 찾습니다(카카오 Local API 연결 전).

[숙소]
- 일차별 숙소 변경, "예약 전 확인"(엘리베이터·주차·전화) 칸.

[이동 비교]
- 일정 사이 이동: 도보/버스/택시 시간·금액, "버스·택시 인원별 비용 비교".
- 여행 중 화면의 "지금 위치에서 가는 시간" 카드:
  지금 위치 -> 다음 장소까지 도보·버스·택시 시간과 금액, 추천 표시.
  "버스 도착까지 ○분"을 넣으면 대기시간 포함해 다시 비교.
  멀면(약 20분 이상) 가까운 대안 장소 3곳 + "일정에 넣기".

[지금 시각·위치에 맞추기]
- 여행 당일 화면에 "⏱ 지금 시각·위치에 맞출까요?" 안내가 뜹니다. "예, 맞추기"를 누르면
  지난 장소는 빼고, 지금 시각(5분 올림)·현재 위치에서 출발하도록 남은 일정을 다시 맞춥니다.
  "나중에"를 누르면 그날은 숨깁니다. 자동으로 마음대로 바꾸지는 않습니다.
  위치를 못 가져오면 시각만 맞춥니다. 식사는 새로 잡히므로 이미 드셨으면 빼 주세요.

[근처 · 행사 · 알림]
- "근처 더 보기": 가볼 곳/식당/카페 가까운 순.
- 해당 위치의 행사·축제는 일정 안과 하단에 표시(현재 샘플 데이터).
- 알림 빈도: 자주 / 보통 / 조용히 / 끄기.

3. 아직 안 된 것 / 한계
==================================================
- 모든 장소·식당·카페·행사·가격은 "샘플" 데이터입니다. 새로 추가한 지역은 좌표·요금을 기억 기반으로 넣은 대략값이라 공개 전 TourAPI 등으로 검증해야 합니다.
- 이동 시간·금액은 직선거리 기반 대략값입니다(카카오 길찾기 연결 시 정확해짐).
- 실시간 버스 도착은 자동이 아니라 직접 분(分)을 입력합니다.
- 행사 "일정에 넣기"는 실제 행사 데이터 필요. 하루 고정 행사는 1개까지.
- 숙소 가격·후기는 가져올 수 없음(TourAPI는 이름·주소·전화·주차 정도).
- 숙박비는 아직 1박 단일 가격 기준.
- 앱을 닫아 둔 상태의 알림(푸시)은 서버 연동 후 가능. 지금은 화면이 열려 있을 때만 울립니다.
- 소리로 안내(음성 읽어주기)는 아직 없음. 서버 연동 단계에서 함께 진행하기로 함.
